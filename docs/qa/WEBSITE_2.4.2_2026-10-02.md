# 官网内容、下载与小屏体验更新

- 从已发布的 2.4.2+4032 安装包建立明确的 Android 通用 APK / Windows x64 ZIP 入口，提供版本、构建号、日期和发行说明/校验文件入口。iOS 不提供下载按钮，明确标注本版暂无安装包。
- 新增打卡、目录/评分对比、外观与内存优化介绍，以及安装、升级、账号同步范围、网页演示、镜像与反馈的常见问题。统计图片和进度更新标为示意，不宣称网站连接真实账号或已经完成设备验收。
- 演示收藏进度与首页操作一致，完成的作品可转入看过；演示数量来自现有样例。默认不自动切页，用户主动开启的轮播在页面隐藏、离开视口或系统减少动态效果时暂停；交互后停止轮播，保留数据直到页面刷新。
- 新增手机可见的主导航、足够触控高度的演示切换按钮、键盘跳转与焦点样式。修复首屏网格被固定宽度演示撑宽的问题，保留手机端非官方声明；品牌主按钮采用暖粉背景和深色文字。
- 截图复核包含 1366、390、320px，页面几何检查没有横向溢出。下载区和首屏分别复核，iOS 的不可用状态使用中性样式。

验证使用项目固定 Node 22.23.2，保持依赖与锁文件。最终以 `tool/verify_all.ps1 -Mode Full -Areas website,tools` 的报告、当前提交的 Pages 工作流和部署后的实际回读为准；不会把配置存在写成已部署通过。

官网当前继承用户主站 blog.wweiyi.com 的 Pages 域名。检测时 DNS CNAME 指向 GitHub，HTTP 正常，HTTPS 证书未生成。重置主站域名绑定涉及本项目之外的共用博客配置，单独确认；页面内容与部署不依赖这项修改，也不擅自修改 DNS。
