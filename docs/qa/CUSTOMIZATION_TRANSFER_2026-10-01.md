# 外观、好友分组与加密配置迁移

## 使用入口

- 收藏页的「番剧单」打开目录，发现页保留找作品与超展开。公开目录详情有文字分享按钮和顶部分享按钮，可分享摘要链接或带封面、指标与二维码的图片；私有目录不开放分享。
- 设置 → 外观 → 字体：保留默认字体、霞鹜文楷、Noto Sans SC，新增 Noto Serif SC、站酷快乐体、站酷小薇体。下载只由用户点击触发。支持导入 TTF / OTF / TTC，单文件上限 64 MB，按内容摘要去重，复制到应用字体目录并保留离线选择。
- 设置 → 外观 → 主题颜色：主色、辅助色、浅色背景、深色背景支持色值与色板编辑，先预览后应用；恢复默认保留原有班娘粉主题。自定义背景、文字和按钮保持可读对比度。
- 个人主页 → 查看完整介绍：独立阅读弹窗，支持 Markdown 标题、列表、代码块、图片与表格，图片只接受 HTTP/HTTPS，失败显示替代文字。原 BBCode 介绍和折叠剧透保留。代码内容是显示文本，不执行。
- 好友页 → 管理本地好友分组：新建、重命名、删除、筛选。好友行的分组菜单设置归属。删除分组只让成员回到未分组，分组按当前 UID 独立存储，不向官网写入。

## 配置迁移

1. 两台设备分别登录同一 Bangumi 账号，在「设置 → 加密配置迁移」选择发送/接收。
2. 源设备准备配置，默认随机生成 24 字符口令。外观与好友分组始终包含，可选择新番表、RSS、备注与屏蔽、首页置顶、浏览偏好与搜索历史、推荐反馈。
3. 同一 Wi-Fi 下选择源设备的局域网地址并生成二维码。保持发送页在前台，在接收设备扫码或从二维码图片识别。二维码只包含短期局域网入口和密文校验值，口令需单独输入。
4. 接收设备解密后选择类别，预览影响，再确认导入。默认合并并保留本地冲突项，也可明确选择覆盖所选本地数据。好友分组始终合并并保留本地已有归属。
5. 不同网络或无法连通时，可保存 `.muconfig` 加密文件并在接收设备导入。二维码/临时服务有效期 10 分钟，关闭页面、切换账号、应用进入后台或到期会停止服务；加密文件有效期 24 小时。

迁移不包含 OAuth/API 凭据、网站 Cookie、番键会参与凭据、草稿、缓存、运行数据库文件或待上传队列。字体只传选择标识；字库与壁纸不嵌入，接收设备缺少字体时使用默认字体并提示下载/导入，不自动下载字体。背景只传柔化等偏好，不传文件路径。数据上限 18 MB，备份部分仍遵循已有 16 MB 校验。加密传输不会自动提交官网收藏、进度或好友写操作。

## 加密与网络边界

- 固定版本 `cryptography 2.8.1`，AES-256-GCM；每次使用独立 16 字节盐、12 字节 nonce、16 字节认证标签。
- PBKDF2-HMAC-SHA256 固定 600,000 次迭代派生密钥，口令与加解密任务在 isolate 中处理，不阻塞扫描与界面。
- 格式/盐/nonce/到期时间都纳入认证附加数据；错误口令、篡改、过期、非支持字段会被拒绝。
- 局域网接收只允许字面量 RFC1918 IPv4、固定令牌路径和有效端口，不跟随重定向；请求不携带登录信息或口令。下载有体积、连接、读取和总时限。
- 原有备份的账号归属、预览校验和事务提交逻辑复用；过期账号请求的结果丢弃。外观/分组与备份属于不同存储，部分保存失败会明确提示重新预览，不能声称整个迁移已回滚。

实现依据：[cryptography 官方 API](https://pub.dev/documentation/cryptography/2.8.1/)、[AES-GCM API](https://pub.dev/documentation/cryptography/2.8.1/cryptography/AesGcm-class.html)、[Google Fonts 固定提交](https://github.com/google/fonts/tree/9710da1eacb3be272583c3224dcb70f9da6eadbb/ofl)。字体下载 URL、大小、内容摘要与 OFL 许可均固定，许可随应用分发，新增字库不随安装包下载。
