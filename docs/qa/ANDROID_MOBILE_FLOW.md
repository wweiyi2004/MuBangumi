# Android 手机操作优化 · build 24

本轮按用户要求优先 Android，iOS 系统分享扩展与编译暂不实施。

## 条目页单手操作

手机宽度下，收藏、记进度、写短评固定在底部安全区，滚动长详情时保持可见，顶部去掉重复操作按钮。收藏状态使用底部选择面板；动画/三次元复用章节面板，书籍复用卷/话进度编辑；写短评直接聚焦编辑框。音乐、游戏不展示章节进度入口。

收藏编辑器保存时校验打开面板时的账号及条目修改版本，防止切换账号或外部更新后覆盖新数据。章节修改继续使用现有队列、撤销与账号保护。

## Android 系统分享

Android 注册 text/plain 分享入口，经原生队列和 Flutter 通道接收冷启动与运行中的分享。未进入首页时暂存在当前进程的待处理队列，进入已登录首页后打开。一个分享含多个链接时供用户选择；不支持的内容给出明确提示。

只识别 bgm.tv、bangumi.tv、chii.in（含 www）上的受支持路径：条目、人物、角色、小组话题、条目讨论、章节讨论及对应超展开路径。统一为 bgm.tv 的规范链接，忽略查询与片段；不识别伪装域名、账号信息、非标准端口、写操作路径、无效编号及超长输入。导入链接仅导航，不自动修改收藏或发送内容。

## 社区阅读

话题支持全部、只看楼主、只看好友。好友列表复用分页加载，失败可重试。阅读位置以账号、话题类型与编号分别记录，最多保留每个账号最近 200 个话题。按帖子 ID 恢复；帖子被删则定位到原序号附近并提示。

默认从顶部打开，提供“继续上次阅读”。实际滚动后才保存位置，筛选期间不覆盖完整话题的阅读记录；切后台、退出页面补存，失败提供重试。账号切换清除当前续读状态并重新读取。该记录仅用于本机续读，尚未加入 JSON 数据备份导出内容。

回复面板展示原帖作者及正文片段，帮助确认回复对象，片段不自动拼入发送内容。
