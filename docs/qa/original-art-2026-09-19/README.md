# 放映与记录：原创视觉第一版

已接入代码，尚未打包或发布。以圆角放映窗、播放符号、胶片孔与轻量票根为共同元素，使用原生绘制与主题色，不下载图片或引入额外字体资源。

- `AsciiRefresh`：散点聚合为播放符号，完成显示 OK，失败显示感叹号；保留首次加载下滑、手指下拉与并发刷新合并，支持减少动效。
- 番会荐：顶部渐变横幅换成紧凑标题；结果采用票根，保留详情和不感兴趣，增加通过现有收藏流程加入想看。未修改候选搜索与推荐算法。
- 空状态：搜索无结果、收藏筛选无结果、私信联系人为空接入三个同风格矢量插画。插画不增加读屏冗余，标题仍使用真实状态。

`preview-light.png` / `preview-dark.png` 为实际 Flutter 组件组成的视觉展示板，作品为演示数据；`recommendation-phone.png` 为测试夹具驱动的真实番会荐页面，封面使用缺省占位图，不代表网络图片加载失败。

验证：收藏、搜索、私信与推荐相关首轮 66 项回归通过；票根自适应调整后，推荐、加载和视觉组件 33 项通过，其中包含新增的加入想看后自动排除已收藏推荐测试。字符字体兼容调整后 7 项加载／视觉测试通过。变更文件静态分析无问题，249 个应用 Dart 文件的架构边界检查通过。

截图覆盖深浅主题，推荐回归覆盖 320 / 390 / 1200 像素宽度及 1.0 / 1.8 文字缩放。

## 第二版：收紧留白

根据实际视觉反馈，减少票根封面、内边距和分隔区高度，编号并入标题右侧，去掉窄屏下独立的编号行；操作按钮保留正常触控面积。空状态插画默认宽度由 144 缩至 108，插画与标题间距由 14 缩至 4，带插画的内容区上下 padding 由 28 缩至 14。私信空列表也采用较小插画和间距。

番会荐评分／年份条件收进默认折叠的“更多条件”，摘要展示当前选择，展开和收起不会丢失设置。展示板本身同时缩小画布，避免演示布局产生额外大块留白。

第二版预览为 `preview-light-compact.png`、`preview-dark-compact.png`、`recommendation-phone-compact.png` 和 `recommendation-phone-dark-compact.png`。推荐与设计预览 29 项检查通过，包含条件展开后的选择保留；搜索、收藏与私信相关回归通过，变更文件静态分析无问题。尚未打包或发布。
