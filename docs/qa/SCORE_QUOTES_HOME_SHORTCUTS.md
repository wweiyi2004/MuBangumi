# 评分行情与追番页顶部入口

2026-09-12。根据用户截图，评分趋势的大摘要卡及逐项大卡占用过多首屏空间；追番页四个常用入口放在收藏列表末尾，不便发现和使用。

## 评分趋势

移除大摘要卡，将作品改为平面行情行：序号、作品与个人收藏信息、当前评分、涨跌分值、历史评分曲线。桌面列对齐，使用等宽数字、红涨绿跌及方向图标；零变化保留中性色。曲线仍来自真实评分历史，变化值仍是接口提供的评分差，不引入模拟交易数据。顶部保留紧凑的榜单计数、来源和色彩说明，筛选栏与列表对齐。

窄窗口或大字号时改为上下排列，保持作品名、评分及涨跌可读。已有筛选、原榜单排名、个人评分、详情跳转、刷新失败保留数据和重试行为继续有效。

## 追番页

“新番表、每日放送、番会荐、找新番”移到问候栏之后、“继续追”之前。桌面与顶部操作区一起固定，滚动收藏时仍可点击；手机按可用宽度和字号换行，四个入口直接可见，不再放到横向滚动条或列表末尾。按钮采用紧凑宽度，保留原导航目标。
