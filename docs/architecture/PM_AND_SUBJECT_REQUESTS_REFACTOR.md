## 详情页请求

| 文件 | 职责 |
| --- | --- |
| `subject_comments_controller.dart` | 评论分页、去重、刷新、加载更多和重试 |
| `subject_friends_controller.dart` | 好友列表到好友收藏/短评的两步查询、加载状态和账号保护 |

这些模块通过注入的 API 获取函数和查询回调读取数据，不依赖 Widget、Riverpod 或全局会话控制器。页面仅提供依赖、监听结果并连接重试和导航。原 `SubjectEpisodeLoader` 继续负责章节及进度读取。

### 请求边界与修正

- 原评论、资料、讨论和历史请求主要只检查 `mounted`；现在每次加载都有独立批次，旧成功结果、旧错误和旧请求结束都不能覆盖较新的状态。
- 评论刷新会作废尚未完成的下一页请求；刷新中不能加载更多，连续点击下一页也只发一次请求。去重继续保留无 ID 评论，分页失败保留已有内容并重试同一页。
- 好友查询绑定账号 ID、用户名和登录批次；页面监听这些身份字段，重新登录同一用户名也会重置好友结果。每一步请求返回后均核对身份，避免使用旧账号的好友列表继续查询。
- 条目简介、章节和补充区块独立加载。完整条目信息失败时仍保留进入页面时可用的信息。
- 元数据各请求独立处理失败；其中一项失败时，其余成功内容继续展示，并提供部分加载失败提示。
- 萌娘百科保持按需加载，首次使用正常缓存策略，后续重试强制刷新；加载中重复点击不会重复发起查询。
- 关闭页面后所有新控制器停止发布结果。请求失效表示丢弃旧响应，不宣称已取消底层网络传输。
