# 中文混合检索与三条真实需求验证

日期：2026-09-08。状态：**本地研究原型已验证；未训练、未微调、未接入 Flutter、未发布、未进行手机性能测试。**

## 结论

关键词与 BGE 的固定排名融合改善了本轮已知正例命中；仅用编码器仍不能可靠执行年份、分数和最早排序。
用户给出的三句话揭示了目录缺失、题材标签过宽、元数据冲突等问题。
第三句的严格评分过滤可以执行，前两句仍不能视作完整满足；不能据此宣称推荐准确率达到 85% 或 100%。

当前优先事项是补齐候选目录、区分主要题材与附带元素、维护可信的日期/形式/评分字段，并对未满足的要求给出说明。
本轮证据不足以断言必须微调，也不足以证明手机端已经可用。

## 固定对照方法

- 沿用 [BGE 基线](SEMANTIC_BGE_BASELINE.md) 的 3,220 部作品和 `synopsis` 文本，不重新训练或选择另一版编码器。
- 使用同一 BGE INT8 ONNX、INT8 存储的作品向量、逐条查询编码（batch=1）。模型与向量配对、文本哈希、ID 顺序和源数据哈希均在运行时核验。
- 对照字符 TF-IDF、纯 BGE、两路 RRF，以及增加标签通道的诊断方案。RRF 固定 `k=60`、每路前 100、等权；没有权重搜索。
- 先执行已知硬性过滤，再截断每路排名和融合；同分共享排名，最后用作品 ID 确定顺序。零证据不投票。
- 原有 50 条为开发集。新增 20 条是助手根据资料编写的案例，已知正例 ID 与原有案例不重合，在检查混合排序前固定；它们仍不是人工盲评或真实用户测试集。
- 三条真实用户需求单独检查，不提供预设正例、不计算准确率。有限条件解析器为本次需求新增，不能把这三条再当作解析器的独立盲测。它们没有用于调整 BGE 或 RRF 权重。

RRF 使用排名融合而非把不同分值直接相加，方法参考 [Microsoft 官方 RRF 说明](https://learn.microsoft.com/en-us/azure/search/hybrid-search-ranking)。
编码遵循 [BGE 官方模型说明](https://huggingface.co/BAAI/bge-small-zh-v1.5) 的 CLS、归一化与查询前缀；相似度不是满足需求的概率。

区间采用固定种子 20260908、10,000 次配对重采样，只反映这组案例的抽样波动，不能校正标注偏差或代表用户总体。

仍有明确退步：爵士乐青春案例的《坂道上的阿波罗》在关键词中排第一，融合后未入前十；料理学校案例《食戟之灵》从第五降到第八。

## 三条真实需求：原句直接送入 BGE

这里保留完整原句，不使用新增条件解析器或元数据过滤；分数为固定本地快照。

| 需求 | 纯 BGE 第一项 | 前五项检查 |
| --- | --- | --- |
| 2007–2011 年小众 galgame 的 OVA | 《选择扩散者 WIXOSS》，2014 年，TV | 五项全部不满足年份范围；还混入 TV 和剧场版 |
| 最早的百合番剧 | 《摇曳百合 夏日时光!》，2015 年 | 没有按最早日期排序；本地已有更早候选 |
| 评分大于 8.0 的恋爱喜剧 | 《只要可爱即使是变态你也会喜欢我吧?》，6.1 分 | 五项评分均不大于 8.0：6.1、6.6、7.2、6.2、7.4 |

这些结果说明：**语义相近不等于条件满足**。将评分和年份交给结构化过滤，有直接的验证依据。
原有 50 条中的条件案例使用人工预拆分字段，不能拿其命中率代替本节的原句测试。

### 1. 2007–2011 年小众 galgame 的 OVA

按动画首发年份包含 2007 和 2011、作品形式明确为 OVA、游戏改编相关标签过滤。
“galgame”暂按美少女/视觉小说游戏改编动画理解；“小众”没有客观阈值，先按评分人数从少到多观察，不自动认定冷门。

目录只有五项通过这些已知字段条件：寒蝉《猫杀篇》《煌》《礼》，以及 CLANNAD《杏篇》《智代篇》。
在线核对时，评分人数分别是 3,331、3,499、4,936、8,641、9,537。
**这些结果不足以满足“小众”要求**，不能通过把候选相对排序称为冷门来掩盖缺口。

另行查到的反例：[《你所期望的永远 ～Next Season～》](https://bgm.tv/subject/2172) 为 2007-12-21 首发的 OVA，Bangumi 标记为游戏改，在线核对有 465 人评分。
发行方也明确说明它由同名 PC 游戏改编，见 [Bandai Visual 原始发行公告](https://www.bandainamco.co.jp/releases/images/3/41925.pdf)。
它不在本地源目录中，进一步证明目录覆盖缺失；相对当前五项更少人评分，不等于客观定义下必然“小众”。
该条为排名检查后另行寻找的覆盖探针，**没有加入向量库或上述命中指标**。

同时发现《声优初体验!》的用户标签含 `galgame`，但元标签明确为漫画改。原型增加冲突检查，排除这种假命中。
目前只是有限冲突规则，完整改编来源仍应从作品关联与可靠资料核验。

### 2. 最早的百合番剧

本地共有 542 项具有所接受的百合标签且日期已知、截至查询日期已播出。
按日期排序，第一项为 [《凡尔赛玫瑰》](https://bgm.tv/subject/12579)，1979-10-10；这表示“本地带标签候选中日期最早”。
后续还出现《飞跃巅峰!》《逮捕令 OVA》《少女革命》《吸血姬美夕》，显示宽泛社区标签会将附带元素混进结果。

**本轮未证实任何作品是动画史上最早的百合番。**
“以女性恋爱为核心”“含百合元素”“百合观众常讨论”需要不同标注。
本地目录又不完整，排序不能证明全局最早。若产品要回答这类问题，需要先显示分类口径，配合带来源的历史资料；不能仅依据向量相似度生成断言。

### 3. 评分大于 8.0 的恋爱喜剧

执行 **`score > 8.0`**，并要求已知恋爱和喜剧/搞笑标签；恰好 8.0 不通过。
目录中日期已知且截至 2026-09-08 已播出的候选有 17 项。
前列包括 [《辉夜大小姐想让我告白-超级浪漫-》](https://bgm.tv/subject/317613) 8.3 分、
[《高分少女 第二季》](https://bgm.tv/subject/278569) 8.1 分，分数已在线核对。

未定档但仅两三人评分就超过八分的条目，不作为已播出作品返回。
这次使用已知首播日期过滤，没有临时设定任意最低评分人数。
恋爱/搞笑标签同时存在仍不代表主类型必然是恋爱喜剧，因此数值条件通过不等于整条推荐人工评审通过。

使用只读公开接口 `GET https://api.bgm.tv/v0/subjects/{id}` 核对三组结果各前五项，共 15 个 ID；串行请求，没有读取用户账户数据。
核对开始时间为 **2026-09-08 15:38:44 UTC / 北京时间 23:38:44**，15 项均成功。
上述 15 项的首发日期和评分与本地快照一致，评分人数已有变化。
《CLANNAD》本地 `platform` 为“其他”，在线为 TV，说明形式元数据也需要更新；本轮保留源快照，没有悄悄改变对照语料。
该差异不影响第三句无形式限制的检查；若用户明确要求 TV，就可能造成漏检。
另外对 ID 2172 做了一次公开接口覆盖探针，未进行全库在线刷新。

局部结果的 `known_hard_constraint_violations=0` 只是对现有字段过滤结果的自检；
它不能证明小众、历史最早、主要题材、资料真实性或候选覆盖完整，不能当作零错误率。

## 实现与验证

- 新增固定 RRF、数据驱动标签诊断通道、有限中文条件解析、原句 BGE 对照、逐条结果及配对区间报告。
- 支持本次年份范围、部分年份比较式、阿拉伯/中文小整数集数上限、评分下限、OVA/TV/WEB 和已知标签排除；不是通用自然语言解析器。
- “最好 12 集以内”等软偏好保留说明，不硬过滤；否定词只排除已标注标签并保留无法证明不存在的说明。
- 43 项 Python 测试通过，覆盖原有编码/数据/过滤检查与 RRF、严格大于、年份端点、形式冲突、日期、条件先于去重、否定及软偏好等边界。
- 新增脚本完整执行成功。应用代码未变，本轮不将 Python 测试冒充 Flutter 或手机验收。

模型与原始包仍约 23.9 MB / 27.7 MB，见基线报告；新增关键词索引与手机推理库的体积、内存尚未打包测量。
研究脚本逐条重建 TF-IDF 索引，三条实际查询每条约两秒，不能沿用基线约 6 ms 的 BGE 热查询耗时来声称整个混合流程同样快。
手机端需要常驻或预构建词法索引，并实测完整流程；当前方案没有满足原先 10 MB 总预算。
