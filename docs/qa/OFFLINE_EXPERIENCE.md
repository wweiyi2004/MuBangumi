# 离线体验改进

验证日期：2026-09-14。适用于 Flutter 主线 Android / Windows；本轮未发布新版本。

## 用户可见变化

| 场景 | 当前行为 |
| --- | --- |
| 很久没打开应用，再离线启动 | 已保存的收藏、个人章节快照不再因为超过 30 天而拒绝读取或被按年龄清理 |
| 断网后点“下一集” | 已缓存章节直接用于选取下一集，修改先落盘，不等待章节请求超时；连续操作叠加本地待同步状态 |
| 离线但作品没有章节快照 | 立即提示“该作品尚未缓存章节，请联网打开详情后再更新进度”，不推测章节 ID、不生成无依据的进度 |
| 正常联网点“下一集” | 继续读取最新章节进度，保留其他设备已看进度的核对；收藏读取已退回缓存时允许使用本地章节 |
| 网络恢复 | 在前台合并 600 毫秒内的网络事件，先尝试上传待同步修改，再刷新收藏；同一恢复协调器不并发执行恢复任务 |
| 接入 Wi-Fi 但接口仍不可用 | 保留本地数据与“收藏暂未更新”提示；失败不会造成恢复任务自循环 |
| 查看缓存内容 | 全局提示当前无网络或收藏暂未更新，可重试；恢复的收藏快照和本地章节显示保存时间 |

全局提示位于页面导航之外。进入详情后断网或恢复，不会重建导航栈或返回首页。提示出现时由自身处理顶部安全区，页面剩余区域不重复预留该空间。

## 数据与账号边界

- `CommunityCache` 对 `collections_snapshot:*`、`episode_collections_snapshot:*` 免除 30 天年龄淘汰；容量淘汰时优先保留这两类记录。
- 缓存仍限制为最多 2,000 条、64 MiB JSON 载荷；收藏单份快照仍最多保存 4,000 项。达到容量限制时仍可能淘汰，因此这不是永久备份，也不会自动恢复此前已被清理的记录。
- 发现页快照的 7 天有效期与其他公共缓存的 30 天清理规则保持现有行为。
- `SnapshotItems` 把保存时间与同一次读取结果绑定；待同步修改叠加后保留该元数据。时间表示本地保存，不表示服务器已经确认修改。
- 待同步操作继续通过 SQLite 队列先保存，再更新界面。重试、合并、被阻止操作的处理和切账号保护继续由既有同步模块负责。
- 恢复刷新在上传前捕获当前账号，异步继续执行时核对账号与请求批次；退出后尚未开始的恢复任务不会发起会话刷新。
- 登录身份仍必须来自安全存储中的可信凭据及已验证账号。没有重新启用 SQLite 旧账号恢复，也没有将开发者账户或缓存加入构建。

## 实现入口

- `lib/core/storage/snapshot_cache.dart`：快照读取及保存时间。
- `lib/core/storage/community_cache.dart`：年龄与容量清理策略。
- `lib/features/collection/application/collection_editor.dart`：离线下一集与在线进度核对。
- `lib/features/collection/application/collection_loader.dart`：缓存回退状态与刷新后的快照保存。
- `lib/state/network_status_controller.dart`：可替换的网络监听接口及平台实现。
- `lib/features/sync/application/network_recovery_controller.dart`：去重、前后台调度与串行恢复。
- `lib/widgets/network_recovery_host.dart`：连接网络、会话、生命周期与页面导航。
- `lib/widgets/offline_status_banner.dart`：离线/缓存提示及手动重试。
- `lib/features/subject_detail/application/subject_episode_loader.dart`：章节缓存来源和时间。

平台监听使用 `connectivity_plus` 7.3.1。网络接口可用不等于 Internet 或 Bangumi 可达；Android 回到前台会重新检查网络，详见 [插件官方说明](https://pub.dev/packages/connectivity_plus)。不发送额外探测请求，不读取 Wi-Fi 名称、IP 或登录资料。Windows 为该插件目标显式设置 `/utf-8`，解决中文代码页下的 C4819 编译错误，未修改全局依赖缓存或关闭警告检查。

## 验证

本轮新增 14 项测试：

- 真实 SQLite 临时库：120 天旧快照仍可读取、公共缓存年龄淘汰、个人快照容量优先、账号隔离及退出清理。
- 离线进度：连续更新章节、没有额外章节请求、无缓存提示、读取期间切账号不提交修改。
- 网络调度：旧检查不能覆盖较新事件、插件不可用时回退 unknown、重复事件合并、恢复执行中再次断连重连、后台延迟、错误不循环及销毁保护。
- 界面：320 / 1,200 宽度、1.8 倍字体、恢复后保持详情导航、接口失败保留提示、退出取消待开始的恢复。

同时强化原有会话恢复、章节读取测试，验证时间戳、缓存来源及成功刷新后清除缓存标记；保留正常联网时核对最新进度的回归测试。

检查结果：

- `flutter analyze --no-pub`：通过，无问题。
- `flutter test --no-pub --reporter expanded`：970 项全部通过。
- 启用截图的离线提示测试：4 项通过；已查看两种宽度的大字体截图，无溢出。
- `flutter build apk --debug`：通过。
- `flutter build windows --debug`：通过，原生探针验证后已重新构建正常应用入口。
- Windows 原生探针构建、运行通过：网络查询和事件流均返回 `available`，进程退出码 0。探针不加载应用账号、缓存或 API。

日志及截图保存在忽略的 `.dart_tool/` 下。探针源码为 `tool/qa/network_status_probe.dart`，可用 `flutter build windows --debug -t tool/qa/network_status_probe.dart` 构建；验证结束后需重新构建默认入口以恢复正常应用。

本轮没有断开开发机网络，也没有进行 Android 真机断网/重连验收；自动化故障场景通过可替换网络接口验证，原生探针只证明当前 Windows 环境中的插件查询与订阅可用。

## 尚不覆盖

首次登录、未缓存内容、最新社区内容、短信收发仍需要网络。短信完整历史尚未新增持久化离线阅读；已有草稿保留机制继续生效。图片与其他资源可能因缓存缺失无法显示。本轮没有加入全库预下载、后台下载服务或把所有页面变成完整离线阅读器。
