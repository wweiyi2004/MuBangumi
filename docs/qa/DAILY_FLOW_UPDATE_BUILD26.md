# 日常使用与更新体验 · build 26

日期：2026-09-13。候选版本：2.2.0+26，Android / Windows。iOS 暂缓。

## 用户可见变化

- 首页“继续追”采用小封面与紧凑列表，直接展示已记录集数、进度条、下一集、集数选择和置顶。保留前 18 部预览、查看全部、原有快捷入口及撤销操作。记录进度不代表有新资源可播放。
- 短评按账号数字 ID 与作品 ID 保存本机草稿。停止输入 350ms 后自动保存，离开编辑器、切后台时补存；重开恢复，提交失败保留，收藏写入成功后清除。故意清空已有短评也能恢复。服务器短评有变化时需明确选择恢复草稿或保留当前短评。
- 自动更新使用页内提示，登录页及键盘输入时隐藏；用户主动点开后才展示版本对比、最多三条摘要与可展开的完整说明。明天提醒保存 24 小时，手动检查可查看已跳过版本。
- 整包下载匹配 Android ABI / Windows x64，展示进度，可取消或重试；关闭面板仍继续，入口为“我的 → 检查更新”。下载完成校验字节数和 SHA256，打开前再次校验。
- Android 安装前核对包名、版本递增及相同签名，经系统授权页和安装确认完成更新。Windows 便携包打开下载位置，由用户解压到新目录。Shorebird 补丁下次完整启动应用，不主动退出进程。

## 已验证

- Dart 静态分析通过。
- 全量 Flutter 测试 895 项通过，含原有账号切换、离线队列、首页置顶和撤销回归。
- 新增短评真实 SQLite 关闭重开、账号与作品隔离、空草稿、并发写保护、失败重试和服务器内容冲突测试。
- 更新覆盖构建号比较、可信资产匹配、提醒持久化、网络失败、校验失败、取消后迟到响应及打开前篡改检查。
- 320px、1.0 / 1.8 倍字体下新增首页条目和更新面板布局测试；短评关闭重开恢复已纳入手机编辑流程测试。

## 验收范围与限制

- 本次候选是普通 Flutter 整包，不能用作 Shorebird 补丁。新增 Android 权限与原生安装桥接，需要安装新整包才能使用。
- 系统安装权限页、实际覆盖安装、Windows 打开下载位置尚未进行真机交互验收，不能把编译或组件测试视作这些流程已通过。
- 下载在应用进程内持续；退出整个应用后不保留任务状态，不支持跨进程断点续传。
- 短评草稿只保存在本机，当前个人备份的“社区草稿”选项不导出短评；仅保存短评文字，不保存尚未提交的评分、标签与状态。
- 自动下载依赖 GitHub 发布资产提供 SHA256 digest 和规定命名；不满足时仍可打开发布页。未发布到 GitHub，用户现有版本不会自动获得这批候选功能。
- 更新 APK 要求当前签名集合一致，尚不支持发布签名轮换。

## 建议实际验收

1. 首页点下一集，再撤销；手机大字体检查列表操作是否方便。
2. 写一半短评关闭，再打开确认恢复；切换账号确认不会看到另一账号的草稿；提交后重开不出现旧草稿。
3. 发布后在旧候选检查新版，确认提醒可延后、下载可取消并重试。Android 首次允许安装后返回面板再次安装，覆盖完成检查收藏及草稿仍在。
4. Windows 下载 ZIP，打开位置并解压到新目录，启动核对版本与原账号数据。
