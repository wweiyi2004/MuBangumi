# MuBangumi 2.3.1 — 登录修复与稳定性更新

本版重点修复 Android 消息网页登录反复失效的问题，并改善番键会同步与本地数据管理。

## 修复与改进

- **消息登录**：修复 Cookie 截断、重复编码和过期会话重新注入；网页不跳转时也能自动核验并保存。修正验证页巨大红字提示，验证成功后自动返回应用。
- **账号隔离**：社区与私信服务按作用域管理，社区缓存按账号隔离，降低切换账号时读取旧内容的风险。
- **番键会**：修复迟到请求覆盖新状态；评分和短评按轮次增量同步，拆分高频存储，支持完整评论分批查看及导出。旧活动和未确认命令保留迁移与恢复能力。
- **收藏统计**：缓存、统计和导出明确数据完整性，避免把部分收藏当作全部收藏。
- **架构维护**：解除导航、品牌组件和草稿存储依赖环，增加自动边界检查。

## 安装与后续更新

本版包含 Android 原生登录修复，需要先覆盖安装整包，无需卸载旧版。Android 通用 APK 支持 ARM64、ARMv7 和 x86_64；Windows ZIP 请解压到新目录后运行。

Android 与 Windows 均以 Shorebird 创建 `2.3.1+4029` 基线。安装本版后，后续兼容的 Dart 修复可通过增量补丁下载，下次完整启动生效；原生代码变化仍需整包。旧版普通 Flutter 包不能直接接收该基线的热补丁。

build 4029 用于超过旧版分架构 APK 的最高 versionCode 4028，保证覆盖升级。普通官网在系统浏览器中的登录不会回传到应用，请在应用内完成消息补充验证。

附件包含 Android 安装包、Windows 便携包、独立番键会 Windows 服务包及 SHA256 校验文件。独立服务包需要自行设置管理密码，不包含用户数据库和凭据。

## 验证范围

发布前 Flutter 全量 1,152 项、独立服务 33 项、发布构建 8 项与 Windows 打包安全 13 项检查全部通过；静态分析、架构边界和网页协议样例检查通过。已有浏览器交互与 50 客户端短时回环验证；鸿蒙真机登录、真实热点和长时运行仍需设备实测，未将模拟测试当作真机验证。
