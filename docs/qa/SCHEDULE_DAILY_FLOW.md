# 新番表日常使用改进 · build 23

## 行为

- 未保存视图偏好时，手机与桌面默认显示“今日”；已有偏好继续生效。本周列表、可拖拽周表、季度选择和海报导出保留。顶部计数与视图切换并排，去掉单独的统计行。
- 搜索加番默认参考当前 Bangumi 每日放送中的星期；未收录或查询失败时进入“待安排”，用户可随时手动选星期。结果按钮明确显示目标星期。只加入本地安排，不自动修改账号收藏。
- 今日/本周卡片可直接“加入在看”“看完一集”“查看更新”；周表操作菜单也提供进度入口。章节操作复用账号保护、保存队列及撤销流程，保存期间禁用重复点击。标记看过不会将 RSS 未读条目误当作已读。
- RSS 在登录后的应用前台运行期间，每 30 分钟检查绑定且启用的源；恢复前台时检查是否已过刷新间隔。离开前台停止定时器，正在进行的请求可能继续结束。导入备份后的自动刷新暂停规则保留。关闭应用不抓取 RSS。
- Windows 为每部启用提醒的作品预排未来 8 次每周通知，在启动、恢复前台或修改安排时补齐。其他支持的平台继续使用系统每周重复通知。文案明确这是用户安排的追番时间，不能证明资源实际更新；超过 8 周不开应用不会继续续排。
- 保存记录损坏时读取明确失败，保存、删除会在事务内检查原记录并拒绝覆盖。读取所有季度也会明确失败，防止提醒同步把损坏记录当作已删除。原始 payload 与时间戳保留，可通过已有数据备份恢复流程处理。
