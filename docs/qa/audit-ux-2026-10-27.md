Reviewed search/navigation stacks, common-friends account resets, cover/share dialogs, update host lifecycle, configuration-transfer lifecycle and subject metadata rails. ## Fixed

`lib/features/schedule/presentation/schedule_search_sheet.dart`

- The search sheet automatically focuses its input but its modal builder did not account for the keyboard. Its scrollable viewport extended underneath the keyboard, hiding the bottom search results. Apply the current `MediaQuery.viewInsetsOf(context).bottom` inside the modal surface.
- With the keyboard correctly excluded, the existing fixed empty-state column overflowed by 4.4 px at 390 × 844 with a 300 px keyboard. Make each empty/error state scrollable using the draggable sheet controller; this also lets users drag the sheet from these states.
- Name the icon-only clear-search action with a tooltip.

Only these changes are attributed to this audit; existing AnimeIcon and other worktree edits in the same file predate this work.
