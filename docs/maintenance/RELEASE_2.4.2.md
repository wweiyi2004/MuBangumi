# 2.4.2+4032 交付范围与验收边界

本版整合 2026-10-01 的客户端功能、界面与内存优化，使用独立发布工作区整理提交。原开发工作区、运行中的调试程序和本机账号数据保留。

## 交付范围

- 图片按显示尺寸解码并保留比例，图片缓存上限为 64 MiB；社区 HTML、JSON 与评分历史的已完成响应分别采用 8 MiB 估算预算。内存告警释放临时缓存，保留离线数据、账号、草稿和在途请求合并。
- 隐藏标签页暂停动画而保留状态；海报预加载与绘制共用有尺寸限制的解码键，最多 4 张并发。合成图片测试验证单图解码缓冲的减少，没有将其换算成整个进程的内存下降比例。
- 章节打卡热力图、目录浏览与编辑/分享、独立制作人员列表、评分历史对比、完整介绍阅读、外观/字体/图标调整、好友本地分组与加密配置迁移，以及通知与社区恢复改进。
- 版本与网络 User-Agent 统一为 2.4.2，Android 通用 APK 的 versionCode 为 4032，Windows 为 x64 便携 ZIP。沿用已有 Android 签名；固定官方 Flutter 3.44.7，不更改 Shorebird 2.3.1+4029 基线，不上传热补丁。
- 独立番键会服务端没有改动，继续使用 2.4.0 服务端包。本次不提供 iOS 安装包。

## 发布验证

发布从已提交、干净的源码构建。统一 Full 流程包含 Flutter 分析与测试、Windows 原生存储和 WebView 合成冒烟、Android/Windows 编译、服务端、网站与浏览器、研究工具、架构、隐私和发布工具检查。

最终已执行项目与结果以 Release 附件 verification.json 为准；云端运行只在对应源码的运行实际完成后记录。安装包检查版本、签名、允许的运行文件、SHA-256 以及私密文件与机器路径；公开追溯信息只包含源码、工具、锁文件、产物标识和验证状态，不分发原始日志、OAuth 配置、签名密钥、运行数据或调试符号。

## 尚未完成的人工验收

移动设备实际体验和整机内存对比、真实 OAuth/验证码/会话过期与账号切换业务、专用收件人私信与专用小组/目录写入、后台恢复、系统文件对话框备份互导、通知送达和覆盖安装仍需实际验收。实体打印与服务端公网部署也未验收。

这些项目保持未验收，不生成已通过的人工设备记录；编译与合成回归不替代真实业务场景。真实账号写入测试继续要求明确授权与专用对象。
