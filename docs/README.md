## 目录职责

| 目录 | 内容 | 保留原则 |
| --- | --- | --- |
| `releases/` | 正式版本说明 | 长期保留，与 Git tag 对应 |
| `architecture/` | 架构决策、审查、迁移与复现 | 保留，不能按“旧文件”批量删除 |
| `maintenance/` | 当前实施状态、交付分组与维护入口 | 先看最新实施记录，再解释历史审查的待办 |
| `qa/` | 验收报告、代表性截图、容量与兼容性记录 | 保留关键证据；以对应日期及版本解读 |
| `archive/` | 更早版本的历史评审 | 归档参考，不作为现行实现说明 |

一次性日志、生成截图和打包中转目录放在被忽略的 `.dart_tool/`。文档中引用的该目录路径属于本机辅助记录，并非仓库必备文件；可再生成的输出与需要长期留存的验收证据应区分。维护方式见 [工具说明](../tool/README.md)。
