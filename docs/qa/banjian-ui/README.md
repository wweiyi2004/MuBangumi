# 番键会 UI 设计稿

2026-09-18，供用户先审核界面；尚未接入 Flutter 功能代码或真实活动服务。音频不包含在本次设计中。

`banjian-review.html` 是会话内可交互的设计片段，覆盖设置入口、服务设备、管理台、原生参与和网页参与五个视角。沿用 MuBangumi 的樱粉、浅色内容面板和线条图标，并适配深色模式。

设计重点：

- 服务端与管理端可以同机或分开；管理口令与参与入口分离。
- 原生参与使用 Bangumi 昵称确认入场，网页填写入场名字。成员页只列提交状态，不展示个人分数。
- 原生参与页不占主导航；返回应用后显示临时「返回活动」入口，退出活动后隐藏。
- 评分、评论、结果展示分区；默认不公布汇总，管理端控制开放和截止。
- 局域网与在线托管分别展示，运行中不允许直接切换托管方式。
- 断线评分显示待同步，尚未确认的内容不显示为已保存。

交互包含：加入与改分、匿名评论、评论隐藏/公开、名单、截止/切番/公布结果、选番筛选与排序、修改活动名称、管理锁定、服务停止恢复、导出格式预览。所有数据及操作都是本地演示。

验证：使用真实浏览器测试上述核心流程、跨视角状态一致、未公布结果不可在参与页显示、输入内容按文本展示；在 4 种宽度 × 5 种视角检查无横向溢出。JavaScript 错误为 0，并查看桌面、手机和深色截图。

预览图包括 `admin-desktop.png`、`admin-dark.png`、`settings-entry.png`、`host-device.png`、`native-entry.png`、`native-participation.png`、`web-entry.png`。番剧标题和封面示例取自 Bangumi 公开条目接口：400602、328609、357961、259；活动、人数、评论和评分为演示数据。
