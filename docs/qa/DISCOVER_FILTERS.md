# 发现页精细筛选

日期：2026-09-09。状态：功能已实现，766 项全量测试与静态检查通过，36 张真实字体截图完成验证；安装包尚未重新构建或发布。

## 用户入口与行为

打开“发现 → 筛选”。没有关键词时，可切换“季度/年度浏览”与“条件搜索”；条件搜索允许空关键词。
已有关键词或标签搜索会直接进入搜索筛选。形式、改编来源等原有官方标签放在可展开区域中。

- 最低 Bangumi 评分可输入一位小数，例如 8.1，也可使用常用评分按钮；支持 `≥` 与 `>`，留空表示不限。
- 年份可填写起始和截止年份，包含两端；任意一端可留空。动画最早输入年份沿用 1906，其他类型沿用 1900，最晚为当前年份加一。
- 截止年份早于起始年份、评分超出 0–10 或超过一位小数时，显示字段错误并禁止应用；不会偷偷交换年份或截断评分。
- “隐藏已收藏”按当前账号已加载的收藏即时判断，包括想看、在看、看过、搁置与抛弃。尚未同步到本机的收藏不在可判断范围内，面板说明了这一点。
- 应用后在结果上方展示评分运算符、年份范围及收藏过滤。取消关闭不应用草稿；重置清空草稿条件，应用后生效。
- 清除筛选后，有关键词时继续关键词搜索；没有关键词时返回浏览。切换作品类型清除搜索条件，避免跨类型误用。

## 实现与分页

`DiscoverFiltersSheet` 管理独立的编辑草稿和输入控制器；应用后一次提交给发现页。
`SubjectSearchFilter` 统一数值约束验证及本地结果复核，API 参数与界面都使用相同的含义。

2007–2011 年发送 `air_date: [">=2007-01-01", "<2012-01-01"]`；严格大于 8.0 发送 `rating: [">8.0"]`。
API 约定见 [Bangumi 官方搜索 schema](https://github.com/bangumi/api/blob/master/open-api/v0.yaml)。
API 请求仍保留现有标签、类型、排序和分页参数；收藏隐藏在本机完成。

页面保存原始返回条目，展示时执行评分、年份与收藏过滤。指定数值条件时，未知年份或未评分条目不能通过对应条件。
分页 offset 使用服务端实际返回条目数，不使用显示条目数；整页被筛除时说明“当前已加载条目均被筛除”，保留继续加载和调整筛选。
加载下一页失败会显示重试，重试从失败页面的原 offset 开始。新查询会重置分页，旧请求按查询版本丢弃。
收藏变化会重新计算显示结果，不丢弃原始页，也不把某个账号的已收藏 ID 固定在候选缓存中。
