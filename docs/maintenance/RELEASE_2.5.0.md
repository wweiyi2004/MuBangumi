# 2.5.0+4034 交付范围与升级说明

本版整合当前工作区的交互改进、已发布主线的构建与打包修复，以及 2026-10-21 审计复核中有证据支持的维护项。原开发工作目录与本机凭据、运行数据保留，发布使用独立检出及可追溯的源码提交。

## 动态为什么改为优先联网读官网

旧动态接口本来也是联网接口，但它与 Bangumi 官网更新不同步。排查中出现过接口正常返回 HTTP 200、时间线却明显落后于官网的情况；本地缓存只能保存上次内容，单纯增加刷新次数不能解决来源滞后。

新版打开或刷新动态时优先联网核对官网。缓存用于先显示和断网回看，加载失败或降级会标注，网站页码与旧接口的 ID 游标分别处理。好友动态需通过网页登录核对账号；API 授权与网页登录仍分别存储、分别验证。

网站读请求依旧可能遇到网络错误、会话过期或验证页，不能承诺实时零延迟。相关证据与历史排查见 [动态同步记录](../qa/TIMELINE_SYNC_2026-10-21.md)。

退出与切换账号另有持久清理状态，分别记录 API 凭据、网页登录快照与浏览器 Cookie。清理失败或进程中断后保持阻断并允许重试；旧清理任务的迟到完成不能解除新账号的清理屏障。错误 state 的本机 OAuth 回调返回错误并继续等待有效回调，不交换令牌。

## Windows 数据迁移

个人数据库移到系统用户数据目录，与程序的启动位置和解压目录分开。迁移仅处理应用明确列出的新番表、RSS、偏好、浏览记录、草稿、同步队列和备份协调数据库，不复制网页登录配置、OAuth 文件或整个旧目录。

首次启动会识别当前启动目录或可执行文件目录内的旧数据库。检测到旧版使用痕迹、却找不到旧库位置时，会先显示迁移页面；请退出旧版后选择旧程序目录，也可选择其中的 databases 目录。

复制通过 SQLite 一致性快照完成，包含已提交的 WAL 数据；旧文件保留，已有目标库不覆盖。迁移失败会保留来源信息以便重试。全新安装或明确选择暂不导入时，才以当前用户目录继续。迁移后请继续使用新版，旧目录可保留作备份。

## 发布方式

- Android 通用 APK 的 versionCode 为 4034；Windows 为 x64 ZIP。完整包命名包含版本与构建号。
- 使用 tool/toolchain.json 指定的官方 Flutter 与项目工具链，不升级系统全局 SDK。
- 本版为普通 Flutter 整包，不变更既有 Shorebird 基线，不生成本版云端热补丁验收记录。
- 发布来源记录包含源码、工具、锁文件与最终安装包标识和哈希。数据库、WebView 配置、OAuth 配置文件、模型和调试符号不参与分发。

## 验证与边界

发布前执行聚焦回归、架构与隐私检查，以及 tool/verify_all.ps1 -Mode Full -WindowsSmoke。Full 结果明确列出实际区域、debug 编译配置和未执行项目；Release AOT、签名、最终 ZIP 内容和哈希另行检查。实际结果以本版发布附件中的 verification.json、provenance.json 和 SHA256SUMS.txt 为准。

真人 OAuth/验证码与账号业务、专用对象私信及小组写入、Android/iOS 真机体验、系统文件互导、通知实际送达和覆盖安装未在自动检查中替代人工验收。iOS 原生 Cookie 通道须由 macOS CI 编译核验；本版不提供 iOS 安装包。Docker 镜像固定依赖来源，不能把未运行的容器部署当作通过。

未证实的数字用户名撞号、抽番服务端窗口、Activity 重建后的通知/小组件路由继续保留为待验证。首次登录要求 API 与网页登录的门禁符合现有需求，保持该策略。未知私信 POST 与博客 POST 不自动重放。
