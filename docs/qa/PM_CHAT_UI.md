# 站内短信聊天界面验收

本次在 2.2.0 开发工作区调整短信界面。2.1.2 登录紧急修复分支维持原有范围。

## 交互

- 可用宽度达到 900 时显示左侧会话列表和右侧聊天；窄窗口显示单页聊天，返回后恢复列表。
- 列表显示头像、昵称、主题、摘要、时间、未读标记和选中状态。搜索仅匹配当前收件箱或已发送列表中已经加载的会话，可继续加载更多。
- 双方消息显示头像，自己在右侧；缺少头像或图片加载失败时显示名字首字。消息使用纯色气泡和独立时间分隔，支持选取文字及表情字体回退。
- 默认打开最新消息；向上查看历史后可点击“回到最新”，刷新同一历史列表保留滚动位置。
- 底部输入区支持多行，Enter 换行，Ctrl + Enter 发送；输入法组字时不触发快捷发送。空白消息和发送中的按钮禁用。
- 保留网站登录、主题筛选、分页、新建短信、草稿和失败重试。切换会话和返回前保存草稿；保存失败时留在原会话，发送期间阻止切换。
- 保留服务端短信机制，不增加实时推送、在线状态、正在输入或已读回执。

浅色、深色、390 宽度、1.4 倍字号的四项离屏渲染检查通过。渲染使用虚构会话，不是原生应用截图，也没有发送真实短信。可选截图命令：

```powershell
flutter test --no-pub --dart-define=PM_CHAT_SCREENSHOTS=true test/pm_chat_layout_test.dart --plain-name 'chat shows both avatars'
```

可选截图需将本机 Microsoft YaHei UI 常规与粗体字形提取到忽略目录 `.dart_tool/pm-chat-fonts/msyh-ui.ttf`、`msyhbd-ui.ttf`；还会加载 Windows 的 Segoe UI Emoji。字体不加入仓库或安装包。常规自动测试不依赖这些文件。
