# 观看记录补录：界面与进入体验

## 范围与结果

本轮针对「搬进看过的番」。保留已有工作区修改、账号域与离线队列，不改变好／坏番剧奖的抽取规则。

- 手机使用封面卡片、年份／集数／评分、候选状态及独立操作区；桌面使用卡片与操作说明的双栏布局。占位封面、加载、空候选和网络失败都有明确状态。
- 左滑跳过、右滑收下，拖动提示只重建卡片。按钮继续可用；撤销覆盖收下与跳过，提供查看条目、换一批候选和本次待同步清单。
- 部分看过可直接输入话数并校验上下界。清单展示整部／分集选择，可移除；同步后留在页面继续挑选。挑选未同步时离开需明确放弃；切号关闭弹层并清空本次挑选。
- 首帧绘制后启动目录请求，同时最多处理 2 页；每页返回即更新，第一条请求较慢也不阻塞已返回的其他页。后台补充期间可以操作已有卡片，不突然替换正在阅读的作品。
- 公共目录成功页缓存 10 分钟，最多 12 页，并合并同页在途请求。缓存不包含账号、收藏、挑选或凭据；重新进入仍按当前账号收藏排除。失败请求可重试，失败不显示为「没有符合条件的番」。换一批推进目录分页。
- 牌堆计数改为直接计算剩余候选；标签频次按候选变化更新，排序结果按修改失效。不再在每次界面构建中为计数重新排序并反复扫描标签。

## 验证证据

固定 Flutter 3.44.7。`watched_guess_test.dart` 与 `watched_intake_experience_test.dart` 共 42 项定向检查，覆盖目录逐页显示、慢首请求、在途合并、缓存到期与失败重试、加载及空状态、滑动／撤销、连续点击去重、无同步前写入、迟到关联结果、话数输入、清单移除、账号变更和离开保护。实际执行结论以统一检查 JSON 及定向日志为准。

真实字体截图覆盖 320／390／1200 宽度、深浅主题、1／1.8 倍文字，以及 320×640 大字号的分集操作和清单。新增截图使用固定合成账号与占位封面，位于 `.dart_tool/watched-intake-*.png`；没有读取真实账号或发起真实社区写入。截图逐张检查代表性布局与操作状态，不能仅以无溢出断言替代视觉检查。

Windows Dart CLI 的合成计数基准（30 次均值）：120 个候选时，原计数所需排序路径为 7.72 ms，新计数路径为 0.026 ms；500 个候选时分别为 240.74 ms 与 0.010 ms。对比保留原排序比较器的标签扫描逻辑，核对候选顺序与计数一致。数据和脚本保存在 `.dart_tool/watched-intake-rework/`。这是特定计数路径的 CPU 基准，不是整个页面进入耗时、FPS 或真机改善比例。

最终执行 `tool/verify_all.ps1 -Mode Full -WindowsSmoke`；以本轮生成的 `.dart_tool/verification/*/results.json` 为统一检查结论和源码指纹证据。

## 验证边界

本轮不发布安装包，不进行真实账号写入。移动设备上的首次网络加载、封面解码与滑动帧时间，以及 iOS 构建和系统交互仍单独待验；本机自动测试不替代这些记录。公共目录缓存只覆盖 API 元数据，真实网络和封面下载仍可能有等待。
