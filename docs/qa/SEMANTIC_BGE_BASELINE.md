# 现成 BGE 中文语义检索验证

日期：2026-09-08。状态：**离线原型已实现并运行；未训练、未微调、未接入 Flutter、未发布、未在手机实测。**

## 本轮结论

现成 BGE 能建立手机端语义检索所需的模型与作品向量，但本轮结果**尚不足以直接替换应用推荐**。
作品文本组织方式影响明显：将叙事简介放在前面、去掉混杂的声优与别名后，
INT8 模型的已知正例 Hit@10 从 46% 提升至 66%；Hit@5 仍为 42%。
先完善资料、标注与排序对照，再决定是否微调，不能由本轮的小规模开发集直接断定微调收益。

## 数据和实验设计

- 现有公开作品资料 3,220 条，3,088 条有简介；没有读取其他用户交互或账号数据。
- 资料中有 3,067 条能取得无歧义正片话数，610 条与导出的章节总数不同，117 条年份未知。
  原型取 `infobox.话数`；未知话数/年份不会通过相应硬条件。
- 50 条由助手编写的开发需求在观察模型排名前固定：42 条具体剧情描述、4 条宽泛偏好、4 条显式条件。
  另有否定、域外输入和圈内术语 3 条未评分探针。
- 查询文件 SHA-256：`9c62320d94ea2aeafa4ae02baea90018e6779d8faeea80447f9b67f03d9ba85b`。
- 数据来源 SHA-256：`fc0ef99ef1564145b615867f4e53e1704a1321e252159433276aec42be2ffe24`。
- 条件的拆分为人工提供的结构化字段，**未实现通用自然语言解析**。
- 标注只包含已知正例，未穷举同系列或其他同样相关作品。例如返回同主题续作也可能未计入命中。
  指标不是准确率、满意度或独立测试集成绩，也没有统计显著性结论。
- 第二轮简介文本方案是看过第一轮后做的诊断，两个版本均使用这份开发集。
  后续验收需要新的独立用户查询与人工盲评，不能将第二轮当成未见测试结果。

## 相同目录上的结果

| 文本 | 方法 | 已知正例 Hit@1 | Hit@5 | Hit@10 | MRR@10 |
| --- | --- | ---: | ---: | ---: | ---: |
| 名称、别名、标签、简介 | 应用规则评分（空偏好） | 2% | 2% | 6% | 0.0242 |
| 名称、别名、标签、简介 | 字符 TF-IDF | 26% | 50% | 60% | 0.3717 |
| 名称、别名、标签、简介 | BGE FP32 | 20% | 46% | 48% | 0.2905 |
| 名称、别名、标签、简介 | BGE INT8 + INT8 向量 | 22% | 42% | 46% | 0.2842 |
| 名称、叙事简介、精选题材标签 | 字符 TF-IDF | 26% | 46% | 58% | 0.3403 |
| 名称、叙事简介、精选题材标签 | BGE INT8 + INT8 向量 | 26% | 42% | 66% | 0.3514 |

应用规则对照只在相同完整目录上复现本地评分，不含线上 API 召回、默认最低评分或个人偏好。
不能据此宣称相对完整应用提升了多少。已使用真实 Dart 引擎逐项核对 50 × 3,220 个评分，
最大绝对差异 `3.7638346555e-06`，来自 Python float32 与 Dart double 的精度差。

第二轮宽泛偏好只有 4 条：前 5 命中 2 条，首位命中 0 条；不足以覆盖实际偏好描述。
字符检索的前 5 表现仍高于 BGE，是后续混合排序的重要对照，而非应立即移除的旧方法。

## 模型、体积与耗时

- 模型：`BAAI/bge-small-zh-v1.5`，ONNX 导出来自 `Xenova/bge-small-zh-v1.5`。
- 固定 ONNX 提交：`75c43b069aac4d136ba6bc1122f995fedcfd2781`，下载逐文件校验上游 Git / LFS 哈希。
- 输入上限 384 tokens，作品每批 8 条；查询每次 1 条，添加官方查询前缀，CLS + L2 归一化。
- INT8 模型 **23,903,394 字节**；分词器 439,125 字节。
- 3,220 部作品的 512 维 INT8 向量、缩放系数与 ID 共 1,674,400 字节。
- 含模型、分词器、作品元数据、向量和清单的原型包 **27,671,125 字节，约 27.7 MB**。
- 不包含推理运行库，**不满足原先 10 MB 总预算**；Python 原型会将作品向量还原为浮点，文件大小不等于内存。
- Windows x64 CPU、4 线程、第二轮 50 条逐句热查询：P50 **6.09 ms**，P95 **7.85 ms**。
  包含分词、编码、向量扫描与名称去重；不含模型加载、网络和界面。
- 模型加载观测 104.97 ms；两次完整实验加载值不同，不将其作为可靠冷启动基准。
- **手机耗时、手机峰值内存、推理库安装增量尚未测量**。

第一轮 FP32 与现成 INT8 模型的查询向量平均余弦为 0.9565，前 10 排名重合率约 74.2%。
量化确实改变部分排序，不能宣称完全无损。另将作品向量由 float32 压到 INT8 时，平均余弦为 0.999828，
本轮 Hit@K 没有变化。实际模型单条/批量编码也有量化差异，两个探针最小余弦 0.99227；
部署应固定查询为单条并复用同一编码器版本的目录。

## 验证与文件

- 29 项定向测试通过：正片集数、未知值、条件与排除、去重、指标、缓存失效、包损坏与模型目录错配。
