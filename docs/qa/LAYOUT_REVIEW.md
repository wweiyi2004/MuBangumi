# 布局审核稿 01（2026-09-17）

本次按用户确认的信息结构重排页面，供用户审核。未发布正式版本。

## 按好友组织私聊（2026-09-18）

- 根据用户标注的左侧区域，移除「收到 / 发出」，加载完整好友列表，支持按昵称、用户名或 UID 搜索。未聊过的好友点击后预填收件人并发起私聊。
- 收发列表在后台独立翻页并合并，按好友 UID / 用户名别名关联；同一会话去重保留未读标记。同名用户不按昵称合并，未关联好友的历史记录留在「其他会话」。
- 同一联系人若有多个不同会话 ID，右侧提供「历史会话」入口，保持各会话与草稿独立；不会把好友 UID 当作会话 ID。
- 修正头像文件名带后缀时未解析到 UID 的问题。只接受官方用户头像路径，默认头像与外部图片不推断身份。
- 好友加载和私信验证相互独立；好友页返回或扫码添加后刷新好友列表，保留当前私聊。私信单次同步有请求上限，达到上限时提供继续同步入口。
- 59 项联系人、私信、解析与好友服务测试，以及 10 个布局场景通过；11 个相关文件静态检查通过。使用模拟数据测试发送，没有发送真实私信。
- 桌面私聊预览已包含没聊过的好友；审核图仍为演示账号。

## 私聊与小组讨论视觉稿 03（2026-09-17）

- 消息入口明确为「私聊 / 小组 / 通知」，使用与空间主页一致的留白、线条图标和清晰层级。
- 私聊：紧凑的联系人会话列表、圆形头像、左右气泡；收到 / 发出仍对应真实私信来源，保留原会话主题。桌面左右分栏，手机输入与发送同排。
- 小组：已加入 / 管理的小组改成群入口式列表；进入后展示讨论列表，「发起讨论」继续使用原生小组发帖流程。
- 小组话题：成员回复改为对话样式，自身回复靠右；楼层、楼主、好友、嵌套回复标记、富文本、贴贴及管理操作保留。底部「参与这场讨论」打开原有回复编辑器。
- 通知：嵌入消息中心时缩小重复标题栏，统一底色与未读高亮。
- 功能映射仍为 Bangumi 私信及小组话题，没有模拟在线状态或即时群聊，也没有实际发送测试消息。
- 86 项功能回归及 10 个布局场景通过；相关静态检查通过。覆盖草稿、发送保护、切换会话、回复、编辑删除、阅读位置，以及窄屏 / 大字号。

## 个人空间整体视觉稿 02（2026-09-17）

- 根据用户对“只是排列变化”的反馈，重新统一整个个人页，而非仅更换动态卡片。
- 封面渐变延伸到头像与资料区，头像白边与封面交叠；应用已启用的自定义背景复用为空间封面，图片加载失败使用默认配色。背景图限制解码宽度，尊重高对比度设置。
- 统计收为紧凑的一行；动态、好友动态、日志采用线条图标分类栏，选中态保留小短线。
- 页面使用统一内容底色、边距和文字层级；桌面主栏最大宽度由 980 调整到 820（含边距），减轻横向空旷感。
- 动态昵称用蓝灰色，正文统一为 17 号、1.65 行高；贴贴改为线条图标，回复数量进入互动栏，下方只保留紧凑的“说点什么”入口。实际贴贴选择、回复、更多操作继续沿用原有功能。
- 已检查桌面、手机、大字号与深色模式实际组件截图（演示数据）。8 个预览场景及相关行为回归合计 49 项通过，4 个改动模块静态检查通过。

## 入口关系

- 主导航仍为五项：追番、收藏、发现、消息、我的。
- 我的：个人资料卡、收藏 / 进行中 / 好友数字栏、我的动态 / 好友动态 / 日志。原有设置独立到右上角的设置页。
- 消息：聊天（Bangumi 私信）、已加入 / 管理的小组、通知。右上角进入好友。
- 发现：找作品、超展开。超展开内寻找话题和小组，或查看全站动态；长筛选栏改为三个分类菜单。
- 小组：优先显示讨论，简介和成员信息收进折叠区；右下角发起讨论。
- 收藏统计与年度回顾：移到收藏页“统计与回顾”。
- 动态发布：移到右下角悬浮按钮，与筛选栏分开。
