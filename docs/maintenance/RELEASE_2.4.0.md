# 2.4.0+4030 交付范围与验收边界

本次整合 2026-09-24 维护交付中尚未提交的客户端、打印工坊、网站及工具改动，并核对 GitHub 主分支已发布的登录、私信和镜像修复。原工作分支与本机数据保留，正式交付使用从主分支整理出的提交。

## 本次收尾

- 账号与社区写入、私信读取恢复、发现页查询、本地数据一致性使用已有回归覆盖；私信未知 POST 结果不自动重发。
- Android / Windows 使用 `tool/toolchain.json` 固定的官方 Flutter 构建；版本为 `2.4.0+4030`，通用 APK 保持 versionCode 4030。原 Shorebird 基线不变，本版不启用热补丁。
- 原始测试记录中的本机路径已脱敏。仓库隐私检查同时覆盖未暂存新文件、运行数据库、浏览器资料、密钥签名、模型与调试符号，并有隔离回归测试。发布前另行扫描完整源码中的秘密。
- Windows 包仅从运行文件清单打包，再检查最终 ZIP；本机账号数据库、WebView 配置、OAuth 配置文件、签名密钥和发布符号不参与分发。
- 发布元数据仅含提交、源码指纹、工具及锁文件标识、产物哈希和验证状态。原始日志保留在被忽略的本机目录，公开结果移除绝对路径。

## 自动验证

使用 `tool/verify_all.ps1 -Mode Full -WindowsSmoke` 验证最终源码，覆盖 Flutter 分析与全部测试、Windows 原生存储与 WebView 冒烟、Android / Windows 构建、独立服务端、网站构建与浏览器交互、Python 研究模块和发布工具。

GitHub Actions 的原生构建另行验证 Android、Windows 和 iOS。是否实际通过以本版提交对应的运行结果及 Release 附件为准；配置存在、编译通过和人工业务验收是不同证据。

## 明确未验收的项目

维护者已明确选择正式版发布并接受以下人工验收缺口；没有将它们填写为 passed，也不据此生成 Shorebird 人工验收记录：

- Android / iOS 真机体验、后台恢复与系统文件保存；自动模拟器检查不替代真机操作。
- 当前版本的真实 OAuth、验证码、会话过期，以及专用收件人私信和专用小组发帖。
- Android / Windows 系统文件对话框备份互导、通知实际送达及整包更新安装。
- 实体打印尺寸、长期真实网络负载及独立服务端公网部署。

真实账号写入测试仍须明确授权和专用测试对象。iOS 不在本次可下载安装包范围内；其 CI 构建结果单独记录。后续维护应以这些剩余项目为起点，不能将历史审查中的已修复问题重新计为现存缺陷。
