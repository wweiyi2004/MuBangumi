# M3 新番表列表视图验收记录

日期：2026-09-08。实现及自动化验证完成，未发布。当前版本仍为 `2.1.1+11`；没有上传 GitHub Release 或 Shorebird 补丁。

## 交付行为

- 新增“今日／本周／周表”切换。Android、iOS 首次默认今日，Windows 等桌面平台默认保留周表；显式选择按数字 UID 保存，访客使用独立偏好。切季度不会重置已选视图。
- 今日列出当天星期对应的安排，并保留待安排作品；本周按周一到周日分组。长名称完整换行，显示当前账号的观看进度、每周提醒时间和 RSS 状态。
- RSS 未读更新、没有未读、尚未绑定和状态未就绪分别显示，不把按星期排列的作品当作已确认更新。
- 查看历史或未来季度时使用所选季度自己的数据，并提示这是该季度的每周安排；只有当前季度显示当前周日期。
- 手机使用季度下拉菜单，桌面将当前季度放在快捷栏前部。手机次要工具收进“更多操作”，保留 RSS 未读入口；原有海报导出继续使用周表排版。
- 日期在本地午夜和恢复前台时刷新，可发现前台期间的日期／时区偏移变化；跨日后今日列表回到当天内容，周列表在进入新一周时重置位置。
- 列表和周表共用同一个操作菜单及控制器，支持改星期、移到待安排、删除、提醒、RSS 和打开条目。季度已改变时旧菜单、旧拖拽或迟到的提醒权限结果不能操作新表。
- 新番表保存成功后再提示完成，失败恢复原安排；切季度的读取等待已接受的保存结束。提醒保存失败在设置弹层内提供可见反馈。

通知续排现在会重新取得设备时区。查找下一次提醒采用日历日期构造，避免固定 24 小时加法跨夏令时后偏到另一天；相关差异见 [Dart DateTime.add 文档](https://api.dart.dev/dart-core/DateTime/add.html)。

## 数据变更

浏览偏好数据库升级到版本 3，新增 `schedule_view` 表；已有收藏筛选、搜索历史和首页置顶保留。新番表、RSS 和系统提醒继续使用现有仓库，没有建立另一份列表安排数据。
