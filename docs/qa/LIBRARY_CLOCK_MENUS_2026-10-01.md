# 收藏入口、分享二维码与浮层排版

- 收藏页将标题与“番剧单 / 统计与回顾 / 批量整理”三个入口分开排版。手机端入口固定同排、等宽，窄屏省略装饰图标，按可用宽度统一限制入口文字缩放并保留完整文字；按钮触控高度至少 48px。
- 按用户确认的第一种方案，分享图片的二维码使用现有 GitHub 下载页 HTTPS URL，并在 fragment 中携带公开 Bangumi 内容路径。例如 `https://github.com/wweiyi2004/MuBangumi/releases/latest#subject/42`。系统扫一扫打开下载页，MuBangumi 内扫描同一码会直接进入条目；目录与动态也保持原有目的地及作者标识。摘要文字链接仍为 Bangumi 网页链接。软件不会向二维码任意指定的地址发送登录信息。
- 已以匿名 GET 检查当前下载入口返回 HTTP 200，重定向到 `v2.4.1+4031` 发布页。没有发布新版本、修改官网或承诺系统扫码自动唤起 App。这是用户确认的行为边界。
- 追番页问候语右侧增加本地时区的 `HH:mm` 24 小时时钟，数字采用等宽特性。时钟按分钟边界更新日期和问候语，只更新小组件，不重建列表或重新拉取数据；后台/隐藏时停止计时，恢复时立即刷新，销毁时清理定时器。
- 弹出菜单、MenuAnchor 与 DropdownMenu 统一为 16px 圆角、轻阴影、主题表面色和柔和选中背景。旧式 DropdownButton/FormField 单独补齐圆角与浮层颜色，覆盖收藏状态、小组排序、收藏统计、新番表、RSS、批量整理、番键会、迁移与打印等现有下拉入口。深色、自定义配色与自选字体继续适用。
