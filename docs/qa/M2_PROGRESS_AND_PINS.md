# M2 进度撤销与首页置顶验收记录

日期：2026-09-08。实现及自动化验证完成，未发布。版本仍为 `2.1.1+11`；本阶段没有上传 GitHub Release 或 Shorebird 补丁。

## 交付行为

- 首页和收藏页的“看完下一集”、章节弹层与作品详情的单集格子支持撤销。提示包含作品名称、章节类型与话数；只保留最近一次有效操作。
- 默认提示约 10 秒后关闭。读屏导航模式下持续显示，仍可主动关闭。使用 Flutter 的 Snackbar 交互，并显式设置持续行为；大字体窄屏把操作放在文字下方。参考 [Flutter SnackBar 文档](https://api.flutter.dev/flutter/material/SnackBar-class.html)。
- 撤销写入恢复状态的队列操作，因此离线、原操作上传中以及上传完成后都可处理；本地快照和进度数字同步更新。账号、认证代次、作品及操作版本必须匹配；旧按钮不能覆盖后续修改，写入失败可以重试。
- 同一作品的进度与收藏操作按顺序保存，连续点不同集也能累加正确。特别篇不改变本篇计数。丢弃失败队列记录时，同时清除相应撤销和内存覆盖状态。
- 章节快照按账号与作品保存。详情页和格子复用统一读取流程，旧版不带账号的章节快照不再恢复；网络迟到结果不能覆盖尚未确认的本地操作或请求发出后的新修改。
- 首页作品可直接置顶，管理面板可取消置顶、上下调整顺序。置顶按数字 UID 保存，重复置顶不重复添加；不改变收藏页排序。完成或移除的作品退出“继续追”，有效置顶作品排在其他进行中作品前，预览仍最多 18 部。

## 存储与同步变更

浏览偏好数据库升级至版本 2，增加 `home_pins` 表，保留原有最近搜索和收藏偏好。

同步队列升级至版本 2。同一键的新修改保留原始创建时间与递增修订号，并获得新的自增 ID；按 ID 派发，避免较早章节被反复修改后仍排在更新的进度之前。旧队列按已记录更新时间迁移，保留原负载和修订信息。旧上传确认无法删除替换后的新记录。

如果切换账号时旧上传仍在进行，新账号操作会先落盘；旧上传结束后自动继续处理新账号队列，维持上传顺序。
