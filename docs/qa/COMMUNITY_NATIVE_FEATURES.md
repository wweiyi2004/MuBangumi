# 已确认接口的原生功能实现（2026-09-17）

承接 [能力核查](COMMUNITY_CAPABILITY_AUDIT.md)。本轮实现确认有接口或不依赖新增服务端能力的功能，没有接入未核实的官网上传 / 管理表单。

## 功能入口

- 人物 / 角色详情页：心形按钮显示当前账号收藏状态，支持收藏与取消收藏。按钮处理中禁止重复点击；失败保留原状态；账号切换后重新读取。
- 社区时光机：条目、人物、角色、日志显示可点击对象卡片；批量动态可展开全部。保留对象类型和 ID，不从描述文字猜测跳转目标。
- 时光机吐槽：显示已有贴贴，可添加、更换、取消；其他类型动态不显示不支持的写操作。
- 自己的动态：删除前明确确认会删除动态及其回复。服务层再次校验作者；删除成功后使用本地删除记录过滤在途旧响应，防止内容重新出现。
- 我的 → 我的日志；用户主页 → 日志：原生分页列表，显示公开 / 仅好友可见状态，支持详情和评论。
- 日志详情：作者可编辑。发布与编辑支持标题、BBCode 正文、标签和可见性；编辑不发送 subjectIDs，保留原有条目关联。本轮未增加关联条目的选择和修改界面。
- 日志草稿：使用独立 `blog-v1` 草稿键；把正文、标签、可见性编码为同一版本化载荷，防止恢复私密草稿时误用公开默认值。发布需要 Turnstile，编辑不额外要求该验证。
- 正文与预览：增加常用颜色名、三位 / 六位十六进制颜色、左右 / 居中 / 两端对齐。编辑工具栏可插入颜色和对齐标签。

## 请求与状态保护

- 收藏使用显式 PUT / DELETE，重复点击不会变成多次切换。
- 原生写请求只在明确凭据失效且刷新成功时重试一次；切换账号后不能以新账号重试旧请求。
- 日志发布超时不自动重发，并提示先查看日志列表确认，避免重复发布。
- 日志 PATCH 保留可见性和标签，不改动未编辑的关联条目。
- 新增界面监听账号变化；晚到的旧请求不能覆盖新账号状态。
- 收藏、日志、贴贴或动态删除成功后清理相关网络缓存和时光机快照。

## 测试

- 本轮社区、话题阅读及条目详情相关测试共 151 项，全部通过；新增和修改文件的静态检查无问题。
- Windows Debug 构建通过：`build/windows/x64/runner/Debug/mubangumi.exe`。这是调试构建，不是已发布的正式安装包。

- `test/community_native_test.dart` 覆盖 API 路径与载荷、收藏失败 / 重复点击 / 账号切换、时光机对象 ID 与批量展开、删除确认与作者权限、贴贴失败、日志隐私 / 草稿、超时不重发及认证刷新时的身份变化。
- `test/community_rich_content_test.dart` 增加颜色和对齐嵌套测试，保持剧透默认隐藏。
- 原有社区、话题阅读、条目详情回归测试一并执行。
- 写操作通过模拟接口验证，没有对真实账号发布、修改、删除、收藏或贴贴。
