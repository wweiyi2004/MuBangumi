## 2026-09-07：长标题、个人统计与共享登录

- 海报标题预留三行，收藏列表预留两行；列表高度随字体缩放调整。仍被截断的名称可点按打开可滚动、可选择的完整文本，详情页不再截断主标题和原名。新番表、点格子、推荐、评分趋势与收藏手账复用同一名称组件。
- 「我的」改为单个收藏统计面板，总收藏为 52 号数字，进行中和已完成为 36 号数字；常见手机宽度并列展示两项状态，大字体或长数字时调整布局，并保留完整数值。
- 手机与 Windows 的应用内 OAuth 授权复用网页 Cookie，账号验证成功后才写入安全存储。手机从导航代理直接交回授权结果，并校验回调地址与 state，避免依赖 WebView 的 HTTP 本机导航。
- 私信与小组网页在页面加载完成后自动保存有效登录 Cookie，网页登录页自动返回；指定收件人的私信流程在登录后继续。相同 Cookie 不重复写入，退出或账号切换后迟到的捕获结果不会恢复旧会话。
- iOS 使用插件的原生 Cookie 查询接口读取 HttpOnly 登录 Cookie；个人 Token、系统浏览器授权或已过期会话仍可能需要一次补充网页登录，官网验证码保持不变。
- 验证：`flutter analyze --no-pub lib test` 无问题；全量 `flutter test --no-pub` 399 项通过；`flutter build apk --debug --no-pub` 构建成功。新增布局覆盖 320 / 390 / 1200 宽度、1 / 1.8 倍字体、浅色与深色主题、大收藏数字及完整标题操作。使用 `READABILITY_SCREENSHOTS=true` 渲染并目视检查手机宽度截图。

## 本轮进一步落实的优化

| 功能 | 当前行为 |
| --- | --- |
| 大收藏库 | 每页结果到达即合并显示，首批动画收藏解除首页准备状态；保留尚未刷新的旧条目和本地修改，完整分页结束后才替换该类型收藏。失效的会话可停止后续分页 |
| 社区请求 | HTML / JSON 缓存复用进行中的相同请求，保留 2 分钟有效期和容量限制；账号、令牌变化以及帖子写操作使对应缓存及旧请求失效；手动刷新跳过已完成的缓存 |
| 评分历史、趋势榜 | 公共结果缓存 10 分钟，最多 64 项；相同请求合并，失败不缓存。趋势页新增手动刷新入口 |
| RSS | 最多同时刷新 3 个源；快源完成即可更新未读计数和源状态，单源失败不阻止其他源。继续使用条件请求和持久化去重 |
| 通知 | 后台暂停轮询，恢复前台时仅在距上次成功刷新超过 3 分钟或尚无结果时补请求；不复用旧会话的进行中请求 |
| 磁盘缓存 | 启动打开缓存及后续写入触发维护检查；每 6 小时或累计 50 次写入清理一次。删除超过 30 天的可丢弃记录，并控制在 2000 项、64 MiB JSON 内容以内；登录身份快照由退出登录负责清除 |

磁盘限制针对缓存记录的内容总量，SQLite 删除后释放的数据库页会被复用，数据库文件不会立即缩小。清理不涉及季度表、RSS 数据或待同步操作。

相关实现：`lib/core/network/async_cache.dart`、`lib/core/network/netaba_api.dart`、`lib/core/network/community_service.dart`、`lib/core/network/bangumi_api.dart`、`lib/state/session_controller.dart`、`lib/state/rss_controller.dart`、`lib/state/notify_controller.dart`、`lib/core/storage/community_cache.dart`。

## 社区交互补充优化

- 超展开、小组列表、小组详情和时光机同时开始网络加载与可选缓存恢复，晚到的旧缓存不能覆盖已完成的网络结果，切换筛选后忽略旧请求。
- 社区各列表增加桌面刷新按钮；保留内容刷新时显示进度，刷新失败提供就地重试。话题、小组和动态分页都有可点击的加载与失败重试入口。
- 话题、小组分页使用服务端原始结果数推进偏移，列表展示另行去重，避免重叠页面造成重复请求；空页结束分页。动态分页检查游标是否前进。
- 发送动态回复后仅刷新相应回复列表及计数，保留已加载动态和阅读位置；回复请求也按版本隔离。
- 发帖和回复草稿按账号与回复对象写入独立的本地 SQLite 数据库；编辑时防抖保存，返回和切到后台时补存。离开页面或重启后可继续编辑，发送失败保留文本，发送成功后清除。保存失败显示重试入口，账号在验证期间变化会阻止发送。
- 帖子与小组详情的刷新状态放到页面顶部，去掉底部的重复状态文字。小组卡片高度随字体缩放调整，元信息过长时省略，避免大字号溢出。

已覆盖慢缓存、快速切换、重复分页、空页、失败重试、回复后不重载动态列表、草稿恢复，以及 320 / 1200 宽度下 1.8 倍字体的布局测试。

## 收藏手账与评分趋势

- 收藏统计分为收藏概览与年度回顾，使用昵称、收藏类型占比、个人评分和常用标签呈现个人记录。按作品类型筛选时重新计算统计；标签按单条收藏去重计数。
- 年度回顾增加年度指标、活跃月份柱状图、月份筛选和带评分、短评的作品卡片。年、月统一使用本地时间，并说明依据收藏最后更新时间统计；无日期的收藏只计入总览。
- 评分趋势突出当前评分、变化方向、变化值和历史曲线，支持只看我的收藏，同时保留原榜单名次并显示个人收藏状态、评分。
- 近期榜单与长期提升榜独立显示结果和失败状态；刷新保留现有榜单，提供就地重试。
- 使用浅色、深色主题与响应式排版；测试覆盖 320 / 1200 宽度、1 / 1.8 倍字体、年份及月份切换、未评分和空数据、慢请求、失败重试与收藏筛选。可用 `flutter test --no-pub test/insights_experience_test.dart --dart-define=INSIGHT_SCREENSHOTS=true` 在 Windows 上生成使用本机微软雅黑的渲染截图，输出到 `.dart_tool/insights_*.png`。

## 私信、草稿与收藏导出补充

- 私信刷新期间保留已加载列表，顶部显示刷新进度或就地重试；分页失败保留当前内容并重试同一页。收发件箱保留各自滚动位置，未读提示明确只统计已加载会话。
- 社区草稿使用独立数据库，不参与可丢弃缓存清理；键包含账号、内容类型、话题/小组/动态与回复对象。保存和发送后的清除按顺序执行，避免迟到保存重新生成已发送草稿。文本选择变化不会触发写入。
- 收藏手账的导出入口提供“另存为 JSON”和“分享收藏文件”。另存调用系统文件选择器，分享提供带文件名的完整 UTF-8 JSON 与平板弹出位置；取消不显示导出成功，失败可再次尝试。导出仍包含全部已传入收藏的评分、短评、标签和隐私标记，不受当前手账筛选影响。
- 验证覆盖私信分页重叠、重复请求、旧分页/旧账号响应、发送后发件箱刷新；草稿数据库关闭再打开、账号/话题隔离、系统返回补存、磁盘失败、发送失败及账号切换；导出的 JSON 内容、系统分享参数、保存取消和失败。系统接口使用替身验证，尚未用真实账号或移动设备操作系统分享面板。
