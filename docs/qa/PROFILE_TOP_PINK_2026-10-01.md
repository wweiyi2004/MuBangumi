# 我的回顶、时间文字与官网粉色

- “我的”在滚动超过 240px 后，右侧显示圆形“回到顶部”按钮。宽屏位于内容栏右侧空白处，手机端靠右；底部预留 96px，避开发动态按钮和底部导航。一次点击同时返回个人资料头部与当前动态列表顶部，其他动态标签的滚动位置保留。仅在可回顶时显示，回顶期间防止重复触发，不更改或提交动态。
- 追番问候语后的时间改为同字号、同字重、同颜色、同字体的纯文字，移除底色、胶囊与独立强调样式；数字保留等宽特性。问候语与时间共同适配窄屏，不单独缩放时间。已有分钟更新和后台恢复逻辑保留。
- 默认浅色与深色主题的主色都精确使用 `#F09199`，进度条、看完下一集、选中导航等默认主色动作统一使用此值，粉色填充面上的文字使用深色。之前用于默认小字的深玫瑰色不再作为默认主色。自定义主题仍使用用户设置及原有配色生成逻辑。

官网依据：[Bangumi 官方样式](https://bgm.tv/css/dist/bangumi.min.css?r771)。本轮匿名读取此文件，匹配到 `#f09199` 152 次，没有读取账号或网站会话。

合成回归覆盖：320px 与 1100px 的嵌套滚动回顶、当前列表与头部同时归零、其他标签位置保留；时间与问候语排版一致、无底色；默认深浅主题主色精确相同；“看完下一集”实际继承的文字色、导出 PNG 的进度条像素与目标色一致；自定义颜色继续适用。现有主页、个人页、收藏快捷入口与布局回归一起运行，最终执行结果以 `tool/verify_all.ps1` JSON 为准。没有使用真实账号发布动态、私信或执行其他社区写入，也没有手机实机验收。
