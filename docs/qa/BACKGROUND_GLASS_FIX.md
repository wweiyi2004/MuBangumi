# 背景与材质修正（2.2.0+17）

2026-09-11，根据 `BACKGROUND_GLASS_REVIEW.md` 的检查结果修正。

## 最终行为

- 壁纸仍只模糊一个图层。浅色主题使用提亮遮罩、深色主题使用压暗遮罩；遮罩有最低保护强度，正文和次要文字不再直接暴露于任意深浅图片。
- 卡片、输入框、弹窗、底部弹层、抽屉、菜单使用不透明底色。导航是唯一跟随“导航不透明度”的通用材质层；桌面侧栏通过同一个 `GlassPanel` 接入，不再固定为 55%。短信阅读区继续使用实色。
- 设置预览和应用使用同一个 `BackgroundWallpaper`，模糊值 0–40 线性映射到 sigma 0–18，最后一段不再失效。预览展示导航与正文两个层级。
- 提供“默认纯色 / 柔和背景 / 轻度毛玻璃”推荐样式、“恢复推荐参数”和“减少透明效果”。未选图片或效果停用时禁止无效调整，并说明当前回退原因。
- 高对比度下移除壁纸和透明材质。Windows 通过只读原生接口读取系统高对比度、透明效果偏好和省电状态，并监听变化；回退时保留用户壁纸及参数，恢复正常状态后重新应用。高对比度主题使用 Windows 系统背景、正文和选中颜色；其他平台使用 Flutter 高对比度信息及应用内减少透明效果设置。
- 本功能是应用内壁纸磨砂与导航材质，不捕获桌面或其他应用窗口，不使用系统 Desktop Acrylic。

## 导入和保存

- 不再在界面构建期间同步检查文件；启动恢复和导入时异步验证图片。
- 新导入图片限制 32 MB，解码后最长边限制为 2560，保存静态 PNG 副本至应用支持目录的 `backgrounds`。用户原图保留，动画图片使用首帧。
- 无效导入不替换原背景；恢复路径失效时显示提示并回退纯色。
- 滑杆写入防抖 250 毫秒，结束拖动、关闭设置、应用失去活动状态时提交；写入串行化，启动恢复不会覆盖新操作。保存失败显示提示和重试。
- 仅清理精确受管理目录内符合生成命名规则的旧副本；旧版文档目录或其他位置的原图不自动删除。

## 拖动卡顿修正（2.2.0+18）

用户反馈 build 17 在调整毛玻璃参数时卡顿。新增连续拖动测试确认：30 个拖动帧使应用背景订阅者重建 24 次，松手及保存完成后累计 25 次。此前该订阅也在应用根部重建主题；该测试证明了重复重建，未测量原生窗口的 GPU 帧时间或复现进程挂起。

- 拖动期间保留已应用参数，仅设置内的小预览使用草稿；松手后一次性应用并保存。长时间按住滑杆不触发中途保存；关闭设置、应用失去活动状态时提交草稿。
- 应用背景只订阅实际渲染字段，读取/保存状态不会重建背景。应用主题与导航只订阅启用状态和导航不透明度，调整模糊、柔化及更换图片不会重建整个 MaterialApp。
- 模糊从零开始时保留同一图片组件结构，在滤镜内隔离原图重绘，减少重复绘制。
- 高级调整说明改为“拖动时预览，松手后应用并保存”。推荐样式与减少透明效果会结束正在进行的草稿，避免全局效果停留在旧值。

专项 29 项测试通过。三个滑杆各连续拖动 30 帧均为拖动期间全局背景重建 0 次、松手后 1 次及 1 次写入；另覆盖长按、关闭设置、切换活动状态、保存失败重试和主题订阅隔离。

全项目 835 项测试通过，`flutter analyze --no-pub` 无问题。自动化验证确认上述更新次数和交互行为，Windows 实际拖动流畅度仍待使用新版验收。
