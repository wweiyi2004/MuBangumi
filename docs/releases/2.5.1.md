# MuBangumi 2.5.1+4035

本版继续改进评分图表、图片分享、观看进度和收藏体验，新增不依赖 GitHub 账号的应用内意见反馈，并合并最新主线中的账号、动态、数据一致性及 Windows 数据迁移修复。

## 主要变化

- 评分历史对比支持双指/滚轮缩放、拖动平移和双指针日期范围；趋势与历史对比可导出并分享图片。
- 底栏页面支持滑动与点击过渡，保留已访问页面的滚动和编辑状态；进度、收藏与评分采用乐观更新，失败时回退。
- 收藏与发现记住视图布局并支持快速回到顶部；筛选搜索区分瞬时网络故障与断网状态。
- 图片分享面板重新整理；新番表和分享图片支持保存到系统相册，每日追番支持横屏放大与分享。
- 重做「搬进看过的番」，支持按片名搜索并连续加入、整部看过或部分进度、卡片选择、撤销、待同步清单和离开保护。
- 修复私信草稿重复入队及旧版空信箱结构误报解析失败，修复新番搜索键盘遮挡、番键会首次状态恢复失败、SQLite 短暂锁竞争及浅色文字对比度问题。

## 应用内意见反馈

入口为「我的 → 设置 → 帮助与反馈 → 意见反馈」。可选择问题、建议或其他类型，填写 1–4000 字正文和选填回复邮箱；版本与平台信息默认携带，但可以关闭。

反馈通过已部署的 Cloudflare Worker 和邮件服务发送，不要求 GitHub 账号，不保存到反馈数据库。只有服务端明确接受后才显示成功，失败时保留输入。

## 升级说明

- Android 使用通用 APK，构建号为 4035，覆盖安装前请保留重要数据备份。
- Windows 使用 x64 ZIP，建议退出旧版并解压到独立目录。个人数据库沿用 2.5.0 起的系统用户目录与迁移流程，旧目录可继续保留作备份。
- 本版使用普通 Flutter 整包，不改变已有 Shorebird 基线，不提供本版热补丁。
- 本版不提供 iOS 安装包。

## 验证与边界

最终验证范围以发布附件中的 `verification.json`、`provenance.json` 和 `SHA256SUMS.txt` 为准。自动化测试、云端编译、最终安装包检查、真实设备与真实账号验收分别记录；未实际执行的项目不会被写成通过。
