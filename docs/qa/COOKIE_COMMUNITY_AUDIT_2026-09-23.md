# Cookie 登录与社区操作检查（2026-09-23）

本轮检查当前工作区的小组、好友、私信及其网站会话依赖，保留已有未提交改动。使用 `tool/toolchain.json` 指定的本地 SDK，没有升级全局 SDK、变更 Shorebird 基线、提交或发布。

## 认证与操作范围

| 功能 | 实际认证路径 | 本轮检查重点 |
| --- | --- | --- |
| 网站登录、补充验证、恢复 | WebView Cookie、网站身份探测、账号绑定 | 过期、验证码、同账号续期、不同账号、迟到请求、存储与浏览器错误 |
| 小组列表、资料、成员、话题 | P1；私密话题有 Cookie HTML 读取兜底 | 缓存归属、分页、权限失败、网页登录恢复 |
| 小组发帖与回复 | P1；仅明确成员拒绝后走 Cookie 表单 | formhash、HTTP 状态、提交回执、账号变化、未知结果不重发 |
| 小组加入、退出、管理 | 已核验 Cookie 的内嵌官网 | 打开页面前核验账号归属，返回后失效成员缓存 |
| 好友列表、共同好友、添加、删除、接受申请 | P1 OAuth，**无需 Cookie** | 账号切换、授权刷新、增删后缓存、分页、旧确认框 |
| 私信收发箱、会话、发信参数、发送与回复 | Cookie HTML | GET 恢复、会话绑定、POST 回执、重定向、未确认发送不自动重放 |
| 动态、贴贴、日志、提醒、账号偏好 | P1 OAuth | 共享读写客户端的账号隔离，POST / PUT / PATCH / DELETE 回归 |

## 已复现并修复

1. **旧账号响应进入新账号流程。** P1 写入原先只在发请求和刷新授权前检查账号，成功响应及非 401 错误缺少检查；P1 GET 的授权刷新和网络重试也可能跨账号。现在成功、失败、刷新及重试均受原账号修订号约束，缓存命中后的异步返回同样核验。账号从有授权到无授权或反向变化也会使旧请求失效，同账号令牌续期仍可继续。
2. **好友增删后列表未失效，旧请求还可重新填充好友缓存。** 原先失效的是目标用户资料，漏掉当前用户的好友列表。现在同时失效好友关系相关缓存，并用关系修订号拒绝增删前的迟到列表及好友状态。
3. **好友分页漏数据。** 原先 offset 使用过滤后的条数，整页无有效用户时提前停止。现在服务和界面均按原始行数推进，支持过滤后的空页继续加载，界面去重不再影响分页位置。
4. **好友、共同好友页残留旧账号内容，旧解除确认可能作用于新账号。** 页面监听账号身份，立即清空旧内容、废弃旧请求并重新读取。解除操作在确认后与完成后核验账号，并限制重复操作。
5. **小组网页提交可能假成功。** 403 表单页面仍能提供 formhash；错误 HTTP 响应带 `posts` 字段、或 `posts: null/false/空值` 都可能被视为回复成功。现在拒绝非成功表单响应，仅接受成功 HTTP 下有效回执，提交后再次核验账号；会话改变时保留待核对结果。登录重定向明确进入补充验证流程。
6. **私信 POST 自动跟随重定向，丢失原始提交回执。** 现在直接核验原始 302/303 回执，不自动跟随或重放 POST；307/308 不能算已发送，登录重定向识别为认证失败。已有私信队列继续保留不确定结果，禁止盲目重发。
7. **打开社区网页时再次读磁盘 Cookie 存在账号切换窗口。** 小组成员设置、私信网页和通用社区网页统一使用经过账号核验的会话快照，打开前再次检查账号修订号；小组成员入口使用固定官方路径。

## 验收边界

本轮没有登录真实网站账号发送私信、发帖、回复、增删好友或加入/退出小组。自动化测试和构建通过可确认所覆盖的客户端行为，不能替代真实站点协议、验证码、设备 WebView 与指定测试账号的验收，也不能证明不存在任何其他缺陷。iOS 和设备验收以验证报告的 deferred 项为准，不虚构通过记录。
