# M4 推荐反馈验收记录

日期：2026-09-08。实现及自动化验证完成，未发布。本阶段未更新 GitHub Release 或 Shorebird 补丁。

## 交付行为

- 每张番会荐卡片提供“不感兴趣”。点击后立即从可见结果中移出，写入失败时恢复原显示并提供重试。
- 顶栏“不感兴趣的作品”入口打开“已隐藏作品”列表，可以逐项恢复。反馈只排除对应 Bangumi 作品 ID，保留原有标签权重、评分、推荐原因和同类作品。
- 记录按数字 UID 保存在本机；访客使用独立范围，不要求补充登录。切换账号后清空旧推荐结果，管理面板不显示原账号的隐藏记录。
- 保存完整候选集合，在排除隐藏和当前已收藏作品后再应用结果数量限制；隐藏后可由其他候选补位，恢复后可重新进入候选。恢复已经收藏的作品仍不会把它推荐出来。
- 全部候选被隐藏时提示恢复或重新推荐。网络全部失败继续保留原候选，部分失败继续显示重试及不完整提示；反馈操作不会清除这些网络状态。
- 读取反馈失败时先提供重试，不在未知隐藏名单的情况下开始推荐。隐藏与恢复写入按顺序执行，单项失败只恢复对应作品，避免覆盖其他成功操作。
- 开始推荐后收起输入键盘；隐藏管理的标题与说明适配手机大字体，恢复失败可在弹层中直接重试。

## 数据变更

浏览偏好数据库升级到版本 4，增加 `recommendation_hidden` 表，记录账号、作品 ID、名称、作品类型和隐藏时间。已有搜索、收藏筛选、置顶与新番表视图偏好保留。没有向 Bangumi 写入收藏或修改推荐偏好；ALS 工具仍未接入。
