# M1 私信草稿验收记录

日期：2026-09-08。实现与自动化验证完成，未发布。版本仍为 `2.1.1+11`；线上 `v2.1.1` 不包含本阶段改动。

## 已实现行为

- 写信保存完整收件人、标题与正文。停止输入 350ms 后保存；返回和切后台补存。新建草稿使用独立 ID，可从“其他草稿”找回较早的文档。
- 回复按账号、会话和话题区分。切话题及手动刷新前补存；保存失败时保留输入并停留原处。
- 发送前确保草稿已保存。发送失败保留原稿；成功后清除按写入顺序执行，即使页面已离开也会处理。清除失败只提供清除重试，并禁用再次发送。
- 独立 SQLite 保存草稿；删除保留不含正文的版本记录，防止旧编辑器或迟到保存重新生成已发送内容。另一处更新过的草稿不会被旧发送结果删除。
- 使用 Bangumi 数字 UID 隔离草稿。应用内 OAuth 的同次登录记录已核对 UID；旧网站 Cookie 需要从官网自身账号导航核对用户名或 UID。无法核对及账号不一致时不填入草稿。
- 仅认证 Cookie 变化触发重新核对；验证码 Cookie 刷新保留当前输入。身份信息写入与退出登录按顺序执行，旧核验结果不能恢复已退出的会话。
- 回复话题按钮取消固定高度，可随大字体增长。
